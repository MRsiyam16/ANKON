Project: Digital Presence v1.0
Aesthetic: Architectural Minimalism & Premium Web Design  

1. Layout & Structure
The website must reflect the "Agency Cream" and "Obsidian Black" palette found in our brand guidelines, utilizing high-contrast sections to define content.  

Asymmetrical Grids: Use a broken grid system to create visual interest while maintaining a professional, premium feel.

Generous White Space: Emphasize negative space to allow visual assets and typography to breathe, reinforcing the minimalist identity.

Primary Focus: Web design should be highlighted as the agency's primary digital service.

2. Typography (Web-Specific)
Using the Montserrat family as the foundation.[cite: 1]

Hero Headers: Montserrat Bold (All Caps) with extreme tracking (+400). This mimics the airy spacing of the logo.[cite: 1]

Navigation: Montserrat Medium (Size: 13-15px). Minimalist menu with large hover-state indicators.[cite: 1]

Body Copy: Montserrat Regular (Size: 16-18px). Maintain a line height of 1.6em for a cinematic, editorial feel.[cite: 1]

3. Visual Assets & Interaction
Image Treatments: Use high-contrast photography with natural lighting.[cite: 1] Focus on "process" visuals—wireframes, clean UI elements, and minimalist interior/architectural textures.[cite: 1]

Micro-interactions: Subtle fade-ins and parallax scrolling on images to create a premium, "living" canvas.

Call-to-Action (CTA): Utilize "Copper Earth" accents sparingly for buttons to guide the user without breaking the monochrome aesthetic.[cite: 1]

4. Section Breakdown
Hero: Minimalist wordmark animation and a short, punchy value proposition.[cite: 1]

Portfolio (Primary Service): High-quality case studies focusing on UI/UX and web design projects.

The Studio: A section detailing the "Ankon" philosophy (sketching/precision).[cite: 1]

Contact: A clean, form-based footer or dedicated page with a minimalist layout.[cite: 1]

5. Development Constraints
Mobile-First: Ensure the geometric spacing scales perfectly for mobile viewports without cluttering the UI.

Speed: Prioritize lean assets to ensure the "Premium" experience isn't bogged down by load times.[cite: 1]
